# ATM-Transaction-Dashboard-UK
  An interactive Power BI dashboard for exploring ATM activity across the UK, built on a sample dataset of 15,000 transactions from June 2024 to June 2025.
**What’s included**
ATM_Transactions_Dashboard_UK.pbix: the Power BI report
ATM_Transactions_Data.csv: the underlying transaction data
Dataset

Each row is one ATM transaction with the ATM and its city, card type (Visa/MasterCard, Debit/Credit), transaction type (Withdrawal, Deposit, Balance Inquiry, Mini Statement), amount, balance after the transaction, date and time, customer ID, ATM status, transaction status (Success, Failed, Pending), issuing bank, fee charged and currency (GBP).

**Dashboard**
KPI cards: total transactions, total transaction amount, average transaction amount.
Charts: transactions by location, transaction type, card type and month; total transactions by type; fees charged by bank.
Slicers: location, card type, transaction type and bank, with a reset button.
